# 饭碗（AstrBot 插件）

让角色看到自己还剩多少“饭”：模型服务商（DeepSeek）的余额。主人说起大白饭、吃饭、充 token、余额时，她可以自己去看，而不是瞎猜。

## 她能看到什么

工具 `rice_check`，**只在主人私聊里能用**（这是主人的钱包）：

- 现在还剩多少；
- 今天到现在吃了多少，最近几天每天吃了多少；
- 平均每天吃多少，照这样还能吃几天；
- 主人上次什么时候充的、充了多少；
- 最近几天和人聊天吃掉的 token，以及命中缓存的比例（来自 AstrBot 自己的统计，只算聊天回复，不含整理记忆、写日记、上网这些后台调用）。

她拿到的是一段说明，会用自己的话讲出来，不会念一串数字。

## 趋势怎么来的

DeepSeek 只告诉“现在还剩多少”。插件每隔几小时（`check_hours`，默认 3）记一次余额，每次她自己查也记一次：余额变少就是吃掉的，变多就是充了（至少充了这么多）。所以刚装上时还算不出每天吃多少，过半天到一两天才有。查余额本身不收费。

记录存在 `data/plugin_data/astrbot_plugin_rice_bowl/ledger.json`，只保留 60 天。

## 快吃完时

还能吃不到 `warn_days`（默认 5）天，或者余额低于 `warn_balance`（默认 3），在主人私聊里给她附一句提醒（附在主人这句话后面，不进系统提示，不影响缓存），每天最多一次，让她自己决定要不要撒个娇提一句。

## 坏了找谁

没配 DeepSeek 的 key、key 失效、连不上时，工具会告诉她原因和该请主人做什么，她可以转告主人。本事清单（memory-core 的 `being_abilities`）里写着这项本事，没有 key 时也会写明现在看不了。

## 需要

- AstrBot，配好 DeepSeek 提供商（或者在插件设置里填 key）；
- 推荐配合[记忆核心](https://github.com/JikunLiu101/astrbot_plugin_memory_core)（memory-core）：用它的主人 ID 和称呼。没有时用插件设置里的 `owner_ids`，称呼“主人”。

## 支持的平台

只用 AstrBot 的通用消息事件，不依赖哪个平台独有的功能。需要的是：私聊里认得出谁是主人（这是主人的钱包，只在主人私聊里能看）。余额只支持 DeepSeek。元数据里列的是满足这些的主流平台：Telegram、QQ（OneBot / aiocqhttp）、Discord、KOOK、飞书、钉钉、企业微信、Slack。**实际测过的只有 Telegram 和 AstrBot 自带的网页对话**，其他平台欢迎反馈。需要 AstrBot 4.24.2 及以上。
